LOCAL CONTROL PATH

公开浏览与现场控制，使用两个独立入口

二维码只进入项目展示与只读台。真正控制机器人时，操作员应连接树莓派热点或同一局域网，再打开树莓派本地控制页。

  1. 01连接现场网络手机或电脑连接树莓派热点／同一局域网
  2. 02打开本地控制页访问树莓派现场地址，不使用公开链接
  3. 03登录并取得控制权口令认证后，仅一个操作端持有租约
  4. 04选择动作组或 STOP仅 M0/M1/M2/M3/STOP；安全由 STM32 裁决
